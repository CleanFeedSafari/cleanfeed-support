CleanFeed help

A calmer feed starts here.

Set up the Safari extension, fine-tune your filters and find help when something gets in the way.

Enable CleanFeed

  1. Install CleanFeed and open the app for the setup guide.
  2. Open Settings → Apps → Safari → Extensions → CleanFeed Safari. On older iOS versions, Safari is directly under Settings.
  3. Enable the extension. Visit x.com in Safari and allow CleanFeed to access that site.
  4. Reload the X page. Open CleanFeed from Safari’s page/extensions menu.
  5. Select a focus profile and choose the filters you want. Use Edit profile to save account lists, keywords and break limits.

How filtering works

Each profile has independent switches for videos, reposts, replies, blocked post keywords, blocked quote keywords and allow-list matching. You can also hide For You and engagement counts.

With the allow-list filter enabled, a post can match an allowed author or an allowed keyword in the main post. If both lists are empty, there is no allow-list restriction. Enabled blocking filters take priority. Keyword matching ignores case and Turkish diacritics and can match part of a word; text inside images is not read.

Focus lock and breaks

A focus lock lasts 1–180 minutes. It locks profile changes and filtering controls. To end early, keep the panel open for 15 seconds, then hold the exit button for 3 seconds. Leaving the panel resets the wait. When the lock ends, filters remain on. It is a voluntary focus aid; it cannot prevent disabling the extension in Safari or using another app.

Break reminders use active time or viewed-post counts in the current tab. Unlike the focus-lock clock, active time pauses when the tab is not visible and focused. A page reload or profile-rule change resets session statistics.

Profile photos and videos

When Hide videos is enabled, CleanFeed tries to switch the recognized profile media selector to Photos and disables its Videos option. When Hide videos is off, the normal selector remains available. If X changes its controls and automatic switching fails, select Photos manually or use the Switch to Photos notice.

Troubleshooting

The panel says it is not connected.

Open x.com in Safari, check that CleanFeed has permission for the site, and reload the page. Refresh old tabs after installing an update. The extension does not run in the X app.

My feed is empty.

Check your allow lists and blocked words. Multiple filters can hide every loaded post. If focus lock is off, try Pause to compare with the original feed. CleanFeed cannot load missing posts from selected accounts.

For You is still visible, or the feed tab is not recognized.

Select Following manually and reload. X changes its page structure. When CleanFeed cannot confidently identify the selected tab, it keeps the feed usable and shows a notice. Use X in English or Turkish.

The page looks zoomed in.

Open Display in the CleanFeed panel. Enable Open X at 100% zoom or choose Set to 100% now. Automatic reset is applied on page load while filtering is enabled. You can still zoom manually afterward. If Safari rejects the request, choose 100% in Safari’s page menu.

How do I change the language?

Choose System language, Türkçe or English near the top of the extension panel. The native setup guide has its own language preference. Neither changes X’s language.

Can I use Private Browsing?

Only if you separately allow the extension there in Safari. The same saved profiles may be used, so rules added in Private Browsing can remain in local extension storage.

How do I remove my data?

With focus lock off, open Privacy and help → Delete saved profiles and restore defaults. This replaces your custom profiles and rules with defaults, while retaining language and display preferences. Reset in the session section clears temporary statistics. Close or reload the tab to discard its session memory. Remove the app to uninstall the extension; revoking site access alone does not erase saved rules. These actions do not delete your X account or Safari cookies.

Does hiding a video block its download?

No. CleanFeed changes the visible page and pauses recognized videos. X may already have requested media. CleanFeed is not a network blocker.
